## 7. Pièges à connaître (tous rencontrés)
- Ne jamais réécrire un fichier entier par script quand `Edit` suffit ; ne pas modifier `../Goemon64Recomp` ni `../dk64recomp` (références). `lib/` est une **jonction** vers `../Goemon64Recomp/lib` (supprimer avec `cmd /c rmdir lib`, jamais `Remove-Item -Recurse`).
- splat : `rodata_string_guesser_level: 0` obligatoire (sinon décalage silencieux de toute la ROM) ; `generate_asm_macros_files: False` (sinon `include/macro.inc` est écrasé) ; pas de commentaire libre après `// type:func` dans `symbol_addrs.txt` (le mettre sur la ligne d'avant).
- Application graphique Windows : stderr n'existe pas sans `--log` ; la console de `--show-console` se ferme avec le programme.
- RAM N64 en mémoire de la recomp : mots de 32 bits inversés (attention aux empreintes / comparaisons d'octets).
